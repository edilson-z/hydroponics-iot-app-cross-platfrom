# Cross-Platform Hydroponics Tent App

This project presents a cross-platform mobile application for an Artificial Intelligence (AI) and Internet of Things (IoT) enabled hydroponic grow tent that implements the Nutrient Film Technique (NFT) for leafy green plant production. 

## 💻 Technologies 

- `TypeScript`
- `React Native`
- `Expo`

## 🎯 Features
- Light control
- Humidifier control
- Extractor fan control
- Cooling fan control
- pH sensor control
- EC control
- Water level sensor control
- Temperature, water level, humidity, pH Level, and  EC readings

## 🚦 Running the Project

Clone the repository and install the project dependencies:
```bash
git clone https://github.com/edilson-z/hydroponics-iot-app-cross-platform.git

cd hydroponics-iot-app-cross-platform

npm install
```

Launch the Expo Metro Bundler by running:
```bash
npx expo start
```
This will start the local development server and display a **QR Code** in your terminal.

Connect your computer and your mobile phone to the **same Wi-Fi network**.

Scan the terminal QR code:
- **Android:** Open the **Expo Go** app and tap **"Scan QR Code"**.
- **iOS:** Open your phone's native **Camera app** and tap the Expo prompt.
